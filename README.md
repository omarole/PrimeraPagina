# PrimeraPagina
Primera página sencilla del curso.
Página hecha desde cero donde he improvisado y practicado con HTML, CSS y JavaScript.

## Descripción
Se trata de una calculadora que te indica la cantidad de ingredientes necesaria para hacer una tortilla de papas.
Introduce el número de comensales y te devuelve la cantidad de ingredientes que deberías usar para una tortilla para ese número de personas.
